SECURITY FEATURES
================================================================================

NETWORK SEGMENTATION:
  - Root Tunnel: Admin access, split tunnel
  - MCP Tunnel: Service access, split tunnel (VMI01 + Perplexity only)
  - Red Tunnel: Guest access, full tunnel with monitoring

ENCRYPTION:
  - WireGuard: ChaCha20-Poly1305 + Preshared Keys
  - Keycloak: TLS 1.2+ (production)
  - Database: TLS connections

AUTHENTICATION:
  - WireGuard: Public key + PSK
  - Keycloak: Password + MFA (TOTP/WebAuthn)
  - SSH: Key-based only

MONITORING:
  - Suricata IDS/IPS (ET Open ruleset)
  - PiHole DNS filtering (malware/phishing/ads)
  - Centralized logging to VMI01
  - Failed login monitoring

HARDENING:
  - Firewall (UFW + iptables)
  - LAN access blocking (Red tunnel)
  - Brute force protection
  - Rate limiting
  - Audit logging
